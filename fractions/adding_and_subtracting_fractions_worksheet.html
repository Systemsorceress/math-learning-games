🟡 Part 5 — Different Denominators: Concept Check!

⚠️ Important Rule Alert!

You CANNOT simply add denominators together!

❌ WRONG WAY:

1/2 + 1/4 ≠ (1+1)/(2+4) = 2/6

Slices are different sizes, so you can't just count them directly!

✅ RIGHT WAY:

1/2 + 1/4 = 2/4 + 1/4 = 3/4

Convert 1/2 into 2/4 so all slices are quarter-sized!

Fraction Rules Quick Reference

1. SAME DENOMINATOR

Keep the denominator. Add/subtract the numerators directly!

2/5 + 1/5 = 3/5

2. DIFFERENT DENOMINATORS

Make the denominators the same first using equivalent fractions, then add/subtract.

1/2 + 1/4 = 2/4 + 1/4 = 3/4

3. SIMPLIFY & CHECKS

  1. Check the denominators.
  2. Make them the same if needed.
  3. Add or subtract the top numerators.
  4. Keep the bottom denominator.
  5. Simplify your answer if possible!
